## Configure Public Access in Vercel

### Step 1: Go to Vercel Dashboard

1. Visit [https://vercel.com](https://vercel.com)
2. Sign in to your account
3. Click on your project: **"heinthiritun"** (or the project name)

### Step 2: Check Project Settings

1. Click on **"Settings"** tab
2. Scroll to **"General"** section
3. Look for **"Visibility"** or **"Access Control"**

### Step 3: Ensure Public Access

**If you see "Access Control" or "Password Protection":**

1. Make sure **"Password Protection"** is **OFF**
2. Make sure **"Access Control"** is set to **"Public"**
3. If there's a toggle, ensure it's **disabled**

---

## Common Settings to Check

### 1. Project Visibility

**Location**: Settings → General → Visibility

- ✅ Should be: **"Public"**
- ❌ Should NOT be: **"Private"** or **"Restricted"**

### 2. Password Protection

**Location**: Settings → Security → Password Protection

- ✅ Should be: **Disabled** or **OFF**
- ❌ Should NOT be: **Enabled** or **ON**

### 3. Access Control

**Location**: Settings → Security → Access Control

- ✅ Should be: **"Public"** or **"No restrictions"**
- ❌ Should NOT be: **"Restricted"** or **"Private"**

## Troubleshooting

### Problem: Site Shows "Access Denied" or "Password Required"

**Solution**:
1. Go to Vercel Dashboard → Your Project
2. Settings → Security
3. Disable **Password Protection**
4. Save changes
5. Wait 1-2 minutes for changes to propagate

### Problem: Site Not Loading for Others

**Possible Causes**:
1. **Build failed** - Check Vercel dashboard for build errors
2. **DNS propagation** - Wait a few minutes
3. **Browser cache** - Ask them to clear cache or use incognito
4. **Regional restrictions** - Check if there are any geo-restrictions

**Solution**:
1. Check Vercel dashboard → Deployments
2. Verify latest deployment is successful (green status)
3. Check build logs for errors
4. Try accessing from different network/device

### Problem: Want to Add Password Protection (Optional)

If you want to **restrict access** (not recommended for portfolio):

1. Go to Vercel Dashboard → Your Project
2. Settings → Security → Password Protection
3. Enable password protection
4. Set a password
5. Save changes

**Note**: This is usually NOT needed for portfolio sites - keep it public!
