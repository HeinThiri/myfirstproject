# 🚀 Quick Start: Push to GitHub & Deploy

## Step 1: Push Code (3 commands)

```powershell
cd "d:\Hein Thiri\portfolio\myportfolio"
git add .
git commit -m "Update portfolio"
git push origin main
```

**If authentication error:** See [COMPLETE_GITHUB_GUIDE.md](COMPLETE_GITHUB_GUIDE.md) - Part 1, Step 4

---

## Step 2: Enable GitHub Pages (2 clicks)

1. Go to: https://github.com/HeinThiri/myfirstproject/settings/pages
2. Select **"GitHub Actions"** as source → Click **Save**

---

## Step 3: Wait & View

1. Go to **Actions** tab → Wait 2-5 minutes
2. Your site will be live at: **https://heinthiri.github.io/myfirstproject/**

---

## ✅ Done!

Every time you push code, your site updates automatically!
